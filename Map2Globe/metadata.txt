about=Map2Globe is designed first of all to make <b>location and situation maps</b> (locator maps): show where a country, a region or a place is on the globe. It turns the map of your QGIS project into a globe, and back into a flat map, with one click.<br><br><b>Features</b><br>- Countries (Natural Earth data bundled with the plugin: works offline), graticules, oceans and halo, and optional Sentinel-2 cloudless imagery.<br>- Center the globe on the current view, a country, a layer, coordinates or an address.<br>- Colours and styles can be changed, then applied to the existing globe.<br>- "Switch the map to flat" gives back the flat map and keeps the plugin's layers.<br>- French and English interface (FR / EN toggle).<br><br><b>Data and licences</b><br>Natural Earth data: public domain (<a href="https://www.naturalearthdata.com">naturalearthdata.com</a>). The address search uses the <a href="https://wiki.openstreetmap.org/wiki/Nominatim">OpenStreetMap Nominatim</a> API, limited to one request per second by the plugin. Sentinel-2 cloudless by EOX IT Services GmbH (contains modified Copernicus Sentinel data 2017 and 2018) is licensed under <a href="https://creativecommons.org/licenses/by-nc-sa/4.0/">CC BY-NC-SA 4.0</a>: non-commercial use only; for commercial use see <a href="https://cloudless.eox.at">cloudless.eox.at</a>.<br><br><b>Development</b><br>- Pure PyQGIS plugin for QGIS 4 (Qt 6), no external Python dependency; the countries are bundled, so the plugin works offline.<br>- The globe is a custom PROJ azimuthal orthographic projection, registered as a named user CRS ("Map2Globe - ...") and centred with the origin you choose; the halo and the oceans are generated layers saved as files.<br>- Graticules are built with the QGIS Processing algorithms; the address search goes through OpenStreetMap Nominatim.<br>- Developed and tested on QGIS 4.0.1 (Qt 6.8, Python 3.12, GDAL 3.12, PROJ 9.7, GEOS 3.14) on Windows 11, with an automated test suite (pytest and pytest-qgis).<br>- Bilingual interface (French / English) built on plain dictionaries, no compiled translation files.<br><br>Created by ANABA MANGA (<a href="https://anbmng.com">anbmng.com</a>). Based on the GlobeBuilder plugin by Gispo Ltd., released under the GPL.
